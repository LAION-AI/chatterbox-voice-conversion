2 · Diminishing returns — how many candidates?

Expected best-of-k reward (+SIDON) across 52 groups, as % of the full 1→32 gain. This reward deliberately chases the most intense take, so — unlike quality, which saturates by k≈8 — it keeps climbing into the tail: k=4 → 51%, k=8 → 71%, k=16 → 87%. Recommended operating point k=8 (marginal gain drops off after); the strict 90%-of-gain knee only lands at k=32.
